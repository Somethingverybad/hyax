# WYX — перенос функционала WhoYaX на нативный iOS

Цель: полный паритет с веб-клиентом, чтобы сравнить и решить, продолжать ли.
Сервер и API общие. Дизайн — «Мята» как есть. Каждый этап ставится на айфон.

## Этап 1 — переписка (в работе)
- [x] Сокет /ws/user/<id>/: новые сообщения, прочтение, присутствие, реакции, Р.Ё.В
- [x] Форматирование: жирный/курсив/подчёркнутый/зачёркнутый/код/блок кода/спойлер/зальго/перемешать, упоминания, ссылки
- [x] Ответы (цитата), правка, удаление (у меня/у всех), закрепление, копирование
- [x] Реакции: показ, переключение, меню по долгому нажатию
- [x] Подгрузка истории вверх, разделитель непрочитанных, галочки прочтения
- [x] Картинки (полноэкранный просмотр, свайп вниз), видео-файлы, файлы, голосовые (воспроизведение и запись), треугольники (воспроизведение), стикеры (статичные и .tgs)
- [x] Панель стикеров (мои паки, недавние), кнопки ботов
- [ ] Запись треугольника (камера, переворот), панель форматирования, вложения: видео/файл/геопозиция, альбомы
- [ ] Упоминания @ при наборе, inline-боты, звуки сообщений, эффекты (взрыв стикеров)

## Этап 2 — чаты и группы
- [ ] Создание чата/группы/канала, настройки группы, участники, аватар группы
- [ ] Каналы: посты, комментарии, подписка, поиск каналов
- [ ] Закрепление чатов, свайпы (закрепить/удалить), поиск людей по нику
- [ ] Обои чата, пересылка, выбор нескольких сообщений
- [ ] Секретные чаты: ECDH P-256 + HKDF + AES-GCM байт в байт с lib/secret.ts

## Этап 3 — профиль и настройки
- [ ] Профиль: аватар, обложка, о себе; публичный профиль /u/<ник>, ссылка
- [ ] Конфиденциальность, блок-лист, сохранёнки и доступ к ним
- [ ] Уведомления: звуки, паки звуков, Р.Ё.В; стикерпаки (свои, импорт из Telegram)
- [ ] Внешний вид: свои темы (редактор), аура, вайбометр и уровни, «Долгий ящик»
- [ ] Баг-репорт (скриншот + журнал), удаление аккаунта, правила, обновления

## Этап 4 — медиа и звонки
- [ ] Музыка: плейлисты, плеер, общие плейлисты, отправка трека в чат
- [ ] Звонки (WebRTC + CallKit) и групповые звонки
- [ ] Пуши (APNs) и Share Extension

## Сборка
    cd ios-native && xcodegen generate
    xcodebuild -project WYX.xcodeproj -scheme WYX -destination generic/platform=iOS -allowProvisioningUpdates build
Симулятор без DNS (VPN на Mac): прокси `scratchpad/apiproxy.py` + `SIMCTL_CHILD_WYX_API=http://127.0.0.1:8080`,
автовход `SIMCTL_CHILD_WYX_USER/WYX_PASS`, открыть «Избранное» — `SIMCTL_CHILD_WYX_OPEN=saved`.
