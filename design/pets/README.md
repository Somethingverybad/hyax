# Питомцы WYX — формат пака

Питомец — это **пак**: папка `sux-chat-app/public/pets/<вид>/` с файлом `manifest.json` и по одной анимации Lottie на позу. Код приложения общий для всех животных. Новый вид — новый пак плюс одна строка на сервере (`SPECIES` в `backend/chat/pets.py`).

Пример — кот: `design/pets/cat/make_cat.py` собирает его позы кодом. Концепт — `design/pets/cat/concept-*.png`. Позы можно рисовать и в After Effects: экспорт через Bodymovin / LottieFiles с теми же размерами холста.

## manifest.json

```json
{
  "format": 1,
  "species": "dog",
  "rev": 1,
  "name": { "ru": "Пёс", "en": "Dog", "ko": "강아지" },
  "defaultName": { "ru": "Шарик", "en": "Buddy", "ko": "바둑이" },
  "canvas": [200, 240],
  "anchor": [100, 200],
  "scale": 0.3,
  "author": "…",
  "sounds": { "purr": "synth:purr" },
  "palette": { "ink": "#1E1E1E", "fur": "#FFFFFF", "eye": "#1E1E1F" },
  "defaultCoat": "white",
  "coats": {
    "white": { "name": { "ru": "Белый" }, "colors": {} },
    "black": { "name": { "ru": "Чёрный" }, "colors": { "fur": "#3A3A42", "eye": "#F5C842" } }
  },
  "poses": {
    "sit":  { "file": "sit.json",  "loop": true },
    "walk": { "file": "walk.json", "loop": true, "speed": 34, "facing": "right" }
  }
}
```

- `canvas` — размер холста Lottie (`w`, `h` в файле позы), у всех поз один.
- `anchor` — точка на холсте, которой питомец касается **верхнего края пузыря**. Всё, что ниже `anchor[1]`, свешивается через край, на лицевую сторону пузыря: лапы, хвост, одеяло.
- `scale` — пикселей экрана на единицу холста в чате. 0,3 при холсте 240 даёт около 72 px, сидящий кот выходит ростом примерно с пузырь в одну строку. В профиле питомец рисуется крупнее.
- `rev` — поднимать при изменении файлов: файлы кэшируются, и `rev` попадает в их адрес.
- `walk.speed` — скорость ходьбы в пикселях экрана в секунду. `facing` — куда смотрит рисунок; при ходьбе в другую сторону приложение отражает его.
- `sounds.purr` — `synth:purr` (мурчание синтезирует приложение) или имя файла в паке.
- `palette` — слоты окраса: деталь → цвет-метка, которым она нарисована в файлах поз. У каждой детали своя метка. Метки могут отличаться всего на 1/255 и на глаз совпадать (у кота контур `#1E1E1E`, зрачки `#1E1E1F`, усы `#1E1F1E`), важно только, чтобы они не повторялись.
- `coats` — окрасы, их выбирает хозяин в карточке питомца. `colors` — чем заменить метки; слоты, которых нет в `colors`, остаются как в `palette`. Цвета вне палитры (сердечки, миска, плед) не меняются. `defaultCoat` — окрас как нарисовано.

## Окрасы

Приложение при загрузке позы ищет в ней заливки и обводки с цветами из `palette` и меняет их на цвета окраса (`recolor` в `src/lib/pets.ts`). Поэтому:
- Всё, что должно перекрашиваться, рисуйте ровно цветом метки, без градиентов и прозрачности.
- Детали, которые на тёмном окрасе должны остаться видны, держите в отдельных слотах: глаза, блик, нос, усы, кончик хвоста, бантик. Иначе у чёрного кота чёрные глаза пропадут на чёрной морде.
- Новый окрас — одна запись в `coats`, рисунки перерисовывать не нужно. Проверить все окрасы разом: `design/pets/cat-preview/окрасы.png` собирает скрипт превью.

## Позы

Все позы зациклены: первый кадр совпадает с последним, 30 к/с. Нет позы в паке — вместо неё показывается `sit`.

| Поза | Когда показывается | Что рисовать |
|---|---|---|
| `sit` | спокоен, ждёт | сидит; дыхание, хвост, моргание |
| `purr` | тап по питомцу, счастлив | глаза-дуги, лёгкая дрожь, сердечки |
| `walk` | идёт по пузырю | вид сбоку, цикл шага; приложение двигает его само |
| `lie` | скучает, отдыхает | лёг на пузырь, лапы и хвост свешиваются |
| `sleep` | счастлив, ночь | клубком, глаза закрыты, «Z» |
| `belly` | счастлив, объелся | на спине, лапы вверх |
| `scratch` | голоден | царапает пузырь; следы когтей ниже `anchor` |
| `bury` | обижен | закапывает, пыль из-под задних лап |
| `eat` | покормили | ест из миски |
| `sad` | грустит, голоден | уши вниз, грустная мордочка |
| `sick` | шкала на нуле | под пледом, градусник |
| `sulk` | обижен | сидит спиной, хвост дёргается |

## Правила рисунка

- Прозрачный фон. Контур тёмный: в тёмной теме его держит заливка тела.
- Ничего важного за краями холста.
- Мелкие детали теряются: в чате питомец ростом около 50 px.
- Одна поза — один слой шейпов, без растровых картинок, без выражений (expressions) и без эффектов AE: lottie-web их не рисует.
- Файл позы — до ~40 КБ.

## Как питомец ведёт себя в чате

Поведение задаёт приложение (`src/components/pets/ChatPets.tsx`), пак только рисует. По настроению с сервера (`happy`, `content`, `bored`, `hungry`, `lonely`, `sad`, `sick`, `overfed`) питомец выбирает позу и пузырь:
- счастлив — спит на сообщениях хозяина;
- голоден — царапает чужие;
- обижен — закапывает их и садится спиной.

Ночью по часам смотрящего питомец больше спит.

## Проверить пак

```
python3 design/pets/cat/make_cat.py                                  # если пак собирается кодом
node design/pets/preview.mjs sux-chat-app/public/pets/<вид> out.png 0.75
```

Превью — лист: каждая поза в трёх кадрах на «пузыре». Нужен `playwright-core`, его можно подключить через `NODE_PATH` или `npx`.
