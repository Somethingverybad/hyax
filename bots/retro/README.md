# retro — «Ретро-ПК»

Эмулятор x86-компьютера ([v86](https://github.com/copy/v86)) как мини-приложение
WYX: Windows 95/98, DOS и игры для них прямо в мессенджере.

Образы дисков (жёсткий диск, CD, дискета) пользователь выбирает на своём
устройстве — они читаются браузером и на сервер не уходят. Сервер отдаёт
только страницу, v86 и BIOS. Поэтому запускать можно лишь то, что у человека
уже есть: свою копию системы и игр.

## Что умеет

- образ жёсткого диска любого размера читается с устройства кусками;
  его можно запомнить в памяти браузера (OPFS), чтобы не выбирать каждый раз;
- «💾» — снимок всей машины в память устройства (или файлом, если памяти нет);
  «Продолжить с сохранения» возвращает ровно туда же. Изменения диска v86 в
  файл образа не пишет — сохранения игр переживают перезапуск только в снимке;
- мышь пальцем: «Тачпад» (работает с любым драйвером) и «Указатель» — курсор
  встаёт под палец, нужен драйвер абсолютной мыши VMware в гостевой системе
  (VBMOUSE из VBADOS, см. docs/windows-9x.md у v86);
- панель клавиш, которых нет на телефоне (Esc, F1–F12, стрелки, Ctrl+Alt+Del),
  и системная клавиатура для набора текста.

## Устройство

```
public/index.html, app.js, style.css   страница (без сборки)
public/v86/                            v86 0.5.471 (npm, BSD-2) и SeaBIOS/VGABIOS (LGPL), см. VERSION
nginx.conf                             контейнер со статикой
```

Обновить v86: `npm pack v86@<версия>`, скопировать `build/libv86.mjs`,
`v86.wasm`, `v86-fallback.wasm`; BIOS — из `bios/` репозитория v86 того же времени.

## Запуск

Сервис `retro` в docker-compose, `location /retro/` в `nginx/conf.d/sux.conf`:
страница — `https://hyax.ru/retro/`. Мини-приложение бота — `webapp_url` на этот адрес.

Локально: `python3 -m http.server -d public 8092` → `http://localhost:8092/`.
Бесплатные образы для проверки — FreeDOS и KolibriOS (например, с copy.sh/v86).
