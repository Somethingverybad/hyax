Как подготовить Windows 98 с игрой
  1. Нужны свои лицензии: диск Windows 98 SE и игра (например, купленная в GOG).
  2. На компьютере с Linux или macOS поставьте QEMU и создайте диск:
    qemu-img create -f raw win98.img 1500M
  3. Установите Windows с компакт-диска:
    qemu-system-i386 -m 128 -M pc,acpi=off -drive file=win98.img,format=raw -cdrom win98se.iso -boot d
  4. Скопируйте в систему игру: соберите из её папки образ genisoimage -J -r -o game.iso папка_игры и вставьте его как CD (-cdrom game.iso), затем перенесите файлы на диск C:.
  5. Мышь пальцем. Поставьте драйвер VBMOUSE из пакета VBADOS — тогда курсор встаёт туда, куда нажали (режим «Указатель»). Без него работает режим «Тачпад».
  6. Цвета и разрешение. Стандартный драйвер Windows даёт только 640×480 и 16 цветов. Для игр нужен видеодрайвер VBE9x или VMDisp9x (800×600, 16 бит). Игры на DirectDraw с ними идут не всегда — это проверяется на месте.
  7. Выключите Windows (Пуск → Завершение работы) и выберите win98.img здесь как жёсткий диск.

Подробности и решения ошибок — в документации v86.

Эмулятор — v86 (BSD), BIOS — SeaBIOS (LGPL).

Файлы в машину

⚠ В приводе сейчас другой диск — файлы заменят его. Прежний вернётся, если выключить и снова включить машину.

Выбранные файлы станут CD-диском в приводе работающей машины — в Windows это «Мой компьютер» → CD-диск (обычно D:). Длинные и русские имена и папки сохраняются. Один образ .iso вставляется как есть — как настоящий компакт-диск. На сервер ничего не уходит. Диск пропадёт, если выключить машину, — нужное скопируйте на C:.
