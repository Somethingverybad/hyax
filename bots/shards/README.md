# shards — «Осколки Короны»

Пошаговая стратегия на 2–4 игрока внутри WYX (мини-приложение бота): карта
приключений с туманом, города со стройкой и наймом, герои с уровнями и
заклинаниями, бои на гексах. Можно играть с друзьями, против компьютера или
вперемешку.

## Устройство

```
shared/          правила игры — один код для сервера и браузера
  data.js        фракции, существа, постройки, заклинания, баланс
  map.js         генерация карты, поиск пути, туман
  game.js        партия: act(state, игрок, действие) — единственный способ её менять
  battle.js      бой на гексах и ИИ боя
  ai.js          компьютерный игрок на карте
server/
  index.js       статика, комнаты, WebSocket /ws, ходы компьютера, таймер боя
  auth.js        проверка данных запуска WYX (та же подпись, что chat/webapp.py)
  notify.js      бот: отвечает кнопкой «Играть», пишет «ваш ход» в личку
public/          клиент (без сборки): index.html, app.js, render.js, style.css
test/            node --test: правила, подпись, партии компьютер против компьютера
```

Партию считает только сервер: клиент шлёт действие, сервер проверяет его
через `shared/game.js` и рассылает состояние целиком. Партии лежат в
`data/rooms.json` и переживают перезапуск.

Мультиплеер: комната по коду из пяти знаков (или из списка «Ждут игроков»),
ходы по очереди. В бою двух людей защитник ходит в своей очереди отрядов;
на ход в бою — 45 с, затем за игрока ходит ИИ (сразу, если игрока нет в игре).
Пришёл ход, а игрок не в игре — бот пишет ему в личку с кнопкой «К партии».

## Запуск

1. Бот (от владельца, в приложении или запросом) — `POST /api/bots/ {"username": "shards"}`,
   токен из ответа — в `.env`: `SHARDS_BOT_TOKEN=…`.
2. Адрес мини-приложения: `PATCH /api/bots/<id>/ {"webapp_url": "https://hyax.ru/shards/", "webapp_title": "Осколки Короны"}`
   (сам бот своим токеном может). Игра отвечает и на `wyx.su/shards/`, но DNS `wyx.su` бывает недоступен.
3. `docker compose up -d --build --no-deps shards`, затем перезагрузить nginx
   (`location /shards/` в `nginx/conf.d/sux.conf` и `wyx.conf`).

Сейчас бот — `@heroesIII`, ссылка для друзей — `https://wyx.su/u/heroesIII?app`.

## Локально

```
npm install
npm test
DEV=1 npm start          # http://localhost:8090/?dev=Аня — вход без WYX по имени
```

Во втором окне `?dev=Борис` — второй игрок. В DEV в консоли браузера есть
`window.shards` (состояние и действия) — для отладки и автотестов.
