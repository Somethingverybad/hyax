## 📱 Как использовать

### Запись голосового сообщения

1. Откройте чат
2. Нажмите кнопку **микрофона (🎤)** рядом с полем ввода
3. Браузер запросит разрешение на использование микрофона - разрешите
4. Запись начнется автоматически
5. Во время записи:
   - Видно время записи
   - Кнопка ❌ - отменить запись
   - Кнопка ⏹️ - остановить запись

### Отправка голосового сообщения

После остановки записи:
1. Появится плеер для предпросмотра
2. Можете прослушать запись
3. Кнопки:
   - 🗑️ - удалить и записать заново
   - ➤ - отправить голосовое сообщение

### Воспроизведение голосовых сообщений

Полученные голосовые сообщения отображаются как:
- Кнопка Play/Pause (▶️/⏸️)
- Прогресс бар (кликабельный - можно перематывать)
- Текущее время / общая длительность

## 🔧 Технические детали

### Запись аудио:
- Используется **MediaRecorder API**
- Формат: WebM с кодеком Opus
- Настройки:
  - Подавление эха (echoCancellation)
  - Шумоподавление (noiseSuppression)
  - Частота дискретизации: 44100 Hz

### Хранение:
- Файлы сохраняются в `/home/hyax/backend/media/voice/`
- Имя файла: UUID + расширение
- Доступ через nginx: `/media/voice/`

### Производительность:
- Максимальный размер файла: 10MB
- Автоматическая очистка ресурсов
- Оптимизированное воспроизведение

## 🔍 Troubleshooting

### Микрофон не работает:

1. **Проверьте разрешения браузера**:
   - Chrome: Настройки → Конфиденциальность и безопасность → Настройки сайта → Микрофон
   - Firefox: Настройки → Приватность и защита → Разрешения → Микрофон

2. **Проверьте системные настройки**:
   - Windows: Настройки → Конфиденциальность → Микрофон
   - macOS: Системные настройки → Защита и безопасность → Микрофон
   - Linux: проверьте настройки звука в вашей системе

3. **Проверьте HTTPS**:
   - MediaRecorder API требует HTTPS (кроме localhost)

### Голосовые не отображаются:

1. Проверьте консоль браузера (F12) на ошибки
2. Убедитесь, что директория `/home/hyax/backend/media/voice/` существует
3. Проверьте права доступа к директории (должна быть доступна для записи)
4. Убедитесь, что nginx правильно проксирует `/media/`

### Плохое качество звука:

1. Проверьте настройки микрофона в системе
2. Попробуйте использовать внешний микрофон
3. Убедитесь, что рядом нет источников шума

### Голосовые не отправляются:

1. Проверьте размер файла (макс. 10MB)
2. Проверьте логи бэкенда: `docker-compose logs api`
3. Убедитесь, что миграции применены
