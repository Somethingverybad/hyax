# Создание иконок для PWA

Для работы PWA нужны следующие иконки в папке `public/`:

- `pwa-192x192.png` - 192x192 пикселей
- `pwa-512x512.png` - 512x512 пикселей

## Способы создания иконок

### Вариант 1: Онлайн-генератор
1. Используйте онлайн генератор: https://realfavicongenerator.net/
2. Загрузите исходное изображение (например, favicon.ico)
3. Скачайте созданные иконки
4. Поместите их в папку `public/`

### Вариант 2: Используя ImageMagick (если установлен)
```bash
# Создать из favicon.ico
convert public/favicon.ico -resize 192x192 public/pwa-192x192.png
convert public/favicon.ico -resize 512x512 public/pwa-512x512.png
```

### Вариант 3: Используя Python и PIL
```bash
pip install Pillow
python3 create-icons.py
```

### Вариант 4: Ручное создание
1. Создайте квадратное изображение 512x512 пикселей
2. Используйте любой графический редактор (Photoshop, GIMP, Figma)
3. Экспортируйте в PNG
4. Создайте версию 192x192 через ресайз

## Минимальные требования

Иконки должны:
- Быть квадратными (1:1)
- Иметь прозрачный фон или цветной фон (#6366f1 рекомендуется)
- Быть в формате PNG
- Быть четкими при маленьком размере

## Временное решение

Если иконки отсутствуют, PWA все равно будет работать, но браузер может показать стандартную иконку. Vite PWA plugin может генерировать базовые иконки автоматически.
