# Настройка уведомлений в PWA

## Как работают уведомления

Приложение использует Web Notifications API для показа системных уведомлений на мобильных устройствах и десктопах.

### Что реализовано:

1. **Автоматический запрос разрешения** - при первом запуске запрашивается разрешение на уведомления
2. **Уведомления о новых сообщениях** - показываются когда:
   - Приходят новые сообщения в неактивном чате
   - Приложение открыто, но чат не выбран
   - Прошло минимум 3 секунды с последнего уведомления (анти-спам)

3. **Поддержка Service Worker** - уведомления работают через Service Worker для фоновых уведомлений

## Как включить уведомления

1. **Первый запуск:**
   - Браузер автоматически запросит разрешение
   - Нажмите "Разрешить" для включения уведомлений

2. **Если разрешение отклонено:**
   - В Chrome/Edge: Настройки → Сайты → Уведомления → найдите сайт → Разрешить
   - В Safari (iOS): Настройки → Safari → Уведомления → разрешите для сайта
   - В Firefox: Настройки → Приватность и защита → Разрешения → Уведомления

## Особенности на мобильных устройствах

### iOS (Safari):
- **Требуется iOS 16.4 или выше** для поддержки уведомлений в PWA
- Уведомления работают **ТОЛЬКО** когда сайт установлен как PWA (Add to Home Screen)
- После установки PWA уведомления будут работать даже когда приложение закрыто
- Необходимо явно запросить разрешение на уведомления через кнопку в сайдбаре
- Уведомления работают через Service Worker

**Как установить PWA на iOS:**
1. Откройте сайт в Safari
2. Нажмите кнопку "Поделиться" (квадрат со стрелкой)
3. Выберите "На экран «Домой»"
4. После установки откройте приложение с главного экрана
5. Нажмите кнопку колокольчика (🔔) в сайдбаре для запроса разрешения на уведомления

**Если уведомления отключены в настройках браузера:**
1. Откройте **Настройки** на iPhone
2. Перейдите в **Safari** → **Настройки веб-сайтов**
3. Найдите раздел **Уведомления** или найдите ваш сайт в списке
4. Найдите ваш домен (например, `192.168.0.5`) в списке сайтов
5. Установите переключатель **Разрешить** для уведомлений
6. Вернитесь в приложение и нажмите кнопку колокольчика снова

**Альтернативный способ через настройки приложения:**
1. Откройте **Настройки** на iPhone
2. Прокрутите вниз до раздела установленных приложений
3. Найдите ваше PWA приложение (название из manifest)
4. Нажмите на него
5. Включите переключатель **Разрешить уведомления**

### Android (Chrome):
- Уведомления работают сразу после разрешения
- Работают в фоне через Service Worker

## Настройка уведомлений

Уведомления можно настроить в коде:
- Частота проверки новых сообщений: в `Chat.tsx` (refreshChats интервал)
- Минимальное время между уведомлениями: в `use-notifications.ts` (lastNotificationTimeRef)
- Вибрация: настраивается в `use-notifications.ts` (vibrate array)

## Отладка уведомлений

1. Проверьте разрешение в консоли:
   ```javascript
   Notification.permission
   ```

2. Проверьте Service Worker:
   - Chrome DevTools → Application → Service Workers
   - Убедитесь, что Service Worker активен

3. Проверьте логи:
   - Консоль браузера покажет ошибки или предупреждения

## Ограничения

- Уведомления работают только когда сайт открыт (для обычных веб-страниц)
- Для фоновых уведомлений нужна установка PWA
- iOS требует установку PWA для уведомлений
- Android поддерживает уведомления сразу после разрешения
