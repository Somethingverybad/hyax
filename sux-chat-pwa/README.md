# ХУЯКС Мессенджер - PWA версия

Progressive Web App версия мессенджера ХУЯКС.

## Особенности

- ✅ Работает офлайн (Service Worker)
- ✅ Можно установить на устройство (Add to Home Screen)
- ✅ Быстрая загрузка и кэширование
- ✅ Поддержка уведомлений (через браузер)
- ✅ Адаптивный дизайн для мобильных устройств

## Установка зависимостей

```bash
npm install
```

## Разработка

### Локальная разработка (без Docker)

1. Убедитесь, что бэкенд запущен на `http://localhost:8000`
2. Создайте файл `.env` в корне проекта:
   ```
   VITE_API_URL=http://localhost:8000/api
   ```
3. Запустите dev сервер:
   ```bash
   npm run dev
   ```
4. Приложение будет доступно по адресу `http://localhost:5173`

### Разработка с Docker

1. Из корня проекта запустите:
   ```bash
   docker-compose up --build
   ```
2. PWA будет доступно через основной домен (через nginx)
3. Или напрямую: `http://localhost:5173` (если порт проброшен)

## Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`

## Предпросмотр продакшен сборки

```bash
npm run preview
```

## Установка PWA

1. Откройте приложение в браузере
2. В мобильных браузерах: нажмите "Добавить на главный экран"
3. В десктопных браузерах: найдите кнопку установки в адресной строке

## Отличия от Electron версии

- Нет поддержки Electron API
- Нет поддержки Capacitor (нативные функции)
- Использует стандартные браузерные API для сохранения файлов
- Service Worker для офлайн работы
- Манифест для установки как PWA

## Настройка API URL

### Локальная разработка

Создайте файл `.env` в корне проекта:
```
VITE_API_URL=http://localhost:8000/api
```

### Docker (продакшен)

В Docker окружении API_URL автоматически использует относительный путь `/api`, так как PWA и API работают через один домен через nginx.

## Решение проблем

### "Failed to fetch" при регистрации

1. **Локальная разработка:**
   - Убедитесь, что бэкенд запущен на `http://localhost:8000`
   - Проверьте файл `.env` с правильным `VITE_API_URL`
   - Проверьте CORS настройки в `backend/sux_chat/settings.py` (должен быть `http://localhost:5173`)

2. **Docker:**
   - Убедитесь, что все контейнеры запущены: `docker-compose ps`
   - Проверьте логи: `docker-compose logs api pwa nginx`
   - Убедитесь, что сеть создана: `docker network create sux_chat_network`

См. также `../DOCKER_SETUP.md` для подробной инструкции по Docker.
