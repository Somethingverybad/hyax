# ХУЯКС Мессенджер - PWA версия

Progressive Web App версия мессенджера ХУЯКС.

## Особенности

- ✅ Работает офлайн (Service Worker)
- ✅ Можно установить на устройство (Add to Home Screen)
- ✅ Быстрая загрузка и кэширование
- ✅ Поддержка уведомлений (через браузер)
- ✅ Адаптивный дизайн для мобильных устройств

## Установка зависимостей

```bash
npm install
```

## Разработка

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`

## Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`

## Предпросмотр продакшен сборки

```bash
npm run preview
```

## Установка PWA

1. Откройте приложение в браузере
2. В мобильных браузерах: нажмите "Добавить на главный экран"
3. В десктопных браузерах: найдите кнопку установки в адресной строке

## Отличия от Electron версии

- Нет поддержки Electron API
- Нет поддержки Capacitor (нативные функции)
- Использует стандартные браузерные API для сохранения файлов
- Service Worker для офлайн работы
- Манифест для установки как PWA
