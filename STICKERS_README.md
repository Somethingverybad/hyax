## Как использовать

### Первоначальная настройка

1. **Запустите миграцию на бэкенде**:
```bash
cd /home/hyax/backend
python3 manage.py migrate
```

2. **Создайте директорию для стикеров** (если еще не создана):
```bash
mkdir -p /home/hyax/backend/media/stickers
```

3. **Тестовый стикер уже скопирован**:
   - `/home/hyax/backend/media/stickers/test-sticker.webp`

### Использование в приложении

#### Создание стикерпака:

1. Откройте чат
2. Нажмите на кнопку со смайликом (😊) рядом с полем ввода
3. В открывшемся окне нажмите "Настройки" (иконка шестеренки)
4. Перейдите на вкладку "Мои"
5. Нажмите "Создать стикерпак"
6. Введите название и описание
7. Выберите, будет ли пак публичным
8. Нажмите "Создать"

#### Добавление стикеров в пак:

1. В менеджере стикерпаков выберите свой пак
2. Нажмите "Загрузить стикер"
3. Выберите изображение (PNG, JPG, GIF, WebP, макс. 5MB)
4. Стикер будет добавлен в пак

#### Отправка стикера в чат:

1. Нажмите на кнопку со смайликом (😊)
2. Выберите стикерпак из вкладок
3. Нажмите на стикер для отправки

#### Сохранение публичных стикерпаков:

1. Откройте менеджер стикерпаков
2. Перейдите на вкладку "Публичные"
3. Найдите интересующий стикерпак
4. Нажмите "Добавить"
5. Стикерпак появится в ваших сохраненных

#### Удаление стикеров/паков:

1. В менеджере стикерпаков выберите свой пак
2. Для удаления стикера: наведите на него и нажмите иконку корзины
3. Для удаления пака: нажмите иконку корзины рядом с названием пака в списке

## Особенности реализации

### Безопасность:
- Только авторы могут добавлять стикеры в свои паки
- Только авторы могут удалять свои стикерпаки
- Публичные паки доступны всем для просмотра и сохранения

### Ограничения:
- Максимальный размер файла стикера: 5MB
- Поддерживаемые форматы: PNG, JPG, JPEG, GIF, WebP

### Хранение:
- Файлы стикеров хранятся в `/home/hyax/backend/media/stickers/`
- Файлы доступны через nginx по пути `/media/stickers/`

## Структура базы данных

```
StickerPack
├── id (UUID)
├── name (string)
├── description (text, optional)
├── author (FK -> Profile)
├── is_public (boolean)
├── created_at (datetime)
└── updated_at (datetime)

Sticker
├── id (UUID)
├── pack (FK -> StickerPack)
├── file_url (string)
├── file_name (string)
├── emoji (string, optional)
├── order (integer)
└── created_at (datetime)

UserStickerPack
├── id (UUID)
├── user (FK -> Profile)
├── pack (FK -> StickerPack)
└── added_at (datetime)

Message (обновлено)
├── ... (существующие поля)
└── sticker (FK -> Sticker, optional)
```

## Troubleshooting

### Стикеры не загружаются:
- Проверьте, что директория `/home/hyax/backend/media/stickers/` существует и доступна для записи
- Проверьте настройки MEDIA_ROOT и MEDIA_URL в Django settings
- Убедитесь, что nginx правильно проксирует запросы к `/media/`

### Ошибка при создании стикерпака:
- Убедитесь, что миграции применены (`python3 manage.py migrate`)
- Проверьте, что пользователь аутентифицирован

### Стикеры не отображаются в чате:
- Проверьте консоль браузера на наличие ошибок
- Убедитесь, что WebSocket соединение работает корректно
- Проверьте, что файлы стикеров доступны по URL
