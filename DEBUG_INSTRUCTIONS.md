# 🔍 Инструкции по отладке profiles/undefined

## ✅ Что добавлено

### Бэкенд (Django):
- ⚠️ Логи WARNING для каждого запроса профиля
- ❌ Логи ERROR для некорректных ID (undefined/null)
- ✅ Логи INFO для успешных запросов

### Фронтенд (React):
- 📥 Логи загрузки сообщений
- ❌ Проверка сообщений с undefined sender.id
- 🚀 Логи инициализации профиля
- 👤 Логи кликов на профиль

## 🚀 Как проверить прямо сейчас

### Терминал 1: Логи бэкенда
```bash
cd /home/hyax
docker-compose logs -f api | grep -E "(WARNING|ERROR|INFO|👤|🔍|✅|❌)"
```

### Терминал 2 (или вкладка браузера): Приложение
1. Откройте приложение: https://sux.cardiokit.beget.tech
2. Нажмите **F12** (откроется консоль разработчика)
3. Перейдите на вкладку **Console**
4. Нажмите **Ctrl+Shift+R** для полной перезагрузки
5. Войдите в систему (username: loh)

## 🎯 Что делать дальше

### Если видите запросы к undefined:

1. **Скопируйте ВСЕ логи из консоли браузера**
   - Правый клик → Save as... или Ctrl+A → Ctrl+C

2. **Скопируйте логи из терминала с бэкендом**
   - С момента входа в систему

3. **Отправьте оба лога**

4. **Обратите внимание на:**
   - Когда именно происходят запросы к undefined (до/после входа?)
   - Есть ли в логах браузера "❌ Найдены сообщения с undefined sender.id"
   - Какой user делает запрос (loh или AnonymousUser)

## 🔍 Дополнительная диагностика

### Проверка в Network (вкладка Network в F12):

1. Откройте F12 → вкладка **Network**
2. Включите фильтр **XHR**
3. Войдите в систему
4. Найдите запросы к `/api/profiles/undefined/`
5. Кликните на запрос → вкладка **Headers** → **Request Headers**
6. Проверьте **Initiator** (откуда идет запрос)

Это покажет **точный стек вызовов** - какой код на фронтенде отправляет undefined!

## 🎁 Бонус: Быстрая проверка

Откройте консоль браузера и выполните:
```javascript
// Проверить текущего пользователя
localStorage.getItem('user_id')

// Проверить токен
localStorage.getItem('access_token')
```

Если `user_id` === `undefined` или `null` - вот источник проблемы! 🎯
