비밀 채팅은 어떻게 동작하나요

메시지는 내 폰에서 암호화되고 상대방 폰에서만 복호화돼요. 키는 네트워크로 전혀 전송되지 않고, 양쪽이 각자 계산합니다. 어떻게 가능한지는 물감으로 보여 드리는 게 가장 쉬워요.

물감으로

  1. 앨리스와 밥이 같은 공용 물감을 가져와요. 노란색이라고 하죠. 엿듣는 사람까지 모두가 아는 색이에요.
  2. 각자 거기에 자기만의 비밀 색을 섞어요. 앨리스는 빨강, 밥은 파랑. 비밀은 어디로도 나가지 않아요.
  3. 섞은 물감을 서로 교환해요. 엿듣는 사람은 주황색 통과 초록색 통을 봅니다.
  4. 각자 상대의 혼합물에 자기 비밀 색을 한 번 더 섞어요. 둘 다 완전히 같은 갈색을 얻습니다. 이것이 바로 키예요.

물감을 섞기는 쉽지만 다시 원래 색으로 나누는 건 불가능해요. 그래서 엿듣는 사람에게는 노랑, 주황, 초록은 있어도 갈색은 절대 없어요. 누군가의 비밀이 필요하니까요.

숫자로

물감 대신 거듭제곱의 나머지를 써요. 공용 숫자: p = 23 와 g = 5.

  1. 앨리스의 비밀 a = 6. 앨리스가 보내는 값 56 mod 23 = 8.
  2. 밥의 비밀 b = 15. 밥이 보내는 값 515 mod 23 = 19.
  3. 앨리스의 계산 196 mod 23 = 2.
  4. 밥의 계산 815 mod 23 = 2.

공용 키 2 는 둘 다 갖고 있고, 네트워크로 오간 것은 8 와 19뿐이에요. 23이라면 1분이면 비밀을 알아내겠지만, WYX는 256비트 숫자(P-256 타원곡선)를 써서 전수 조사에는 우주의 나이보다 긴 시간이 걸립니다.

서버가 보는 것

양쪽 기기에서 공용 키로부터 암호화 키(HKDF)를 만들고, 모든 메시지를 AES-256-GCM으로 잠가요. 서버에는 암호문, 즉 키 없는 바이트 뭉치만 갑니다. 서버는 보관하고 전달할 뿐 읽을 수 없어요. 키를 가진 적이 없으니까요.

비밀 채팅 메시지는 클라우드 캐시나 백업에 들어가지 않아요. 기기를 잃으면 대화도 함께 사라져요. 다른 어디에도 없다는 것의 대가예요.

암호화는 통로를 지키지, 기기 자체를 지키진 않아요. 화면이나 키보드를 읽는 앱이 폰에 있다면 암호화 전의 텍스트를 보게 됩니다. 폰을 잘 지키고 아무거나 설치하지 마세요.
