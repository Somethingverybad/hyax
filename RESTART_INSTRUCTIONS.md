# Инструкция по перезапуску после добавления стикеров

## Шаг 1: Перезапустить контейнер PWA

```bash
cd /home/hyax
docker-compose restart pwa
```

## Шаг 2: Очистить кэш браузера

После перезапуска контейнера:

1. Откройте приложение в браузере
2. Нажмите `Ctrl+Shift+R` (или `Cmd+Shift+R` на Mac) для жесткой перезагрузки
3. Или очистите кэш браузера:
   - Chrome/Edge: `Ctrl+Shift+Del` → выберите "Изображения и другие файлы" → Очистить
   - Firefox: `Ctrl+Shift+Del` → выберите "Кэш" → Очистить

## Шаг 3: Проверить Service Worker

В DevTools (F12):

1. Перейдите во вкладку "Application" (Chrome) или "Storage" (Firefox)
2. Найдите "Service Workers"
3. Нажмите "Unregister" или "Update"
4. Перезагрузите страницу

## Где искать кнопку стикеров

Кнопка со смайликом (😊) должна появиться в поле ввода сообщений:

```
[📎 Прикрепить] [😊 Стикеры] [________Поле ввода________] [➤ Отправить]
```

Она находится между кнопкой прикрепления файла и полем ввода текста.

## Если кнопка все еще не появляется

### Проверьте консоль браузера (F12):

Если есть ошибки импорта компонентов, они будут видны в консоли.

### Проверьте, что файлы существуют:

```bash
ls -la /home/hyax/sux-chat-pwa/src/components/stickers/
```

Должны быть файлы:
- StickerPicker.tsx
- StickerPackManager.tsx

### Пересоберите заново:

```bash
cd /home/hyax/sux-chat-pwa
npm run build
cd /home/hyax
docker-compose restart pwa
```

### Проверьте логи контейнера:

```bash
docker-compose logs pwa
```

## Альтернатива: Полный перезапуск

Если ничего не помогает:

```bash
cd /home/hyax
docker-compose down
docker-compose up -d
```

Это перезапустит все контейнеры, включая PWA и API.
