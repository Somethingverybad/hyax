## 🚀 Установка

### 1. Создайте директорию для аватаров

```bash
mkdir -p /home/hyax/backend/media/avatars
chmod 777 /home/hyax/backend/media/avatars
```

### 2. Примените миграцию

```bash
cd /home/hyax
docker-compose exec api python manage.py migrate
```

### 3. Перезапустите контейнеры

```bash
cd /home/hyax
docker-compose restart api pwa
```

### 4. Очистите кэш браузера

Нажмите `Ctrl+Shift+R` для жесткой перезагрузки

## 📱 Как использовать

### Просмотр своего профиля

1. Откройте чат
2. Нажмите кнопку **👤** в правом верхнем углу
3. Откроется ваш профиль
4. Нажмите **"Редактировать профиль"** для изменения

### Редактирование профиля

1. В окне редактирования профиля вы можете:
   - **Изменить аватар**: наведите на текущий аватар и нажмите (появится иконка загрузки)
   - **Изменить статус**: введите текст в поле "О себе" (до 500 символов)
2. Нажмите **"Сохранить"** для применения изменений
3. Нажмите **"Отмена"** для выхода без сохранения

### Просмотр профиля собеседника

В чате вы можете открыть профиль собеседника двумя способами:
1. **Клик по аватару** - нажмите на аватар в сообщении
2. **Клик по имени** - нажмите на имя пользователя над сообщением

## 🔧 Технические детали

### Хранение аватаров:

- Файлы сохраняются в `/home/hyax/backend/media/avatars/`
- Имя файла: `avatar_{profile_id}.{расширение}`
- Доступ через nginx: `/media/avatars/`
- Старый аватар автоматически удаляется при загрузке нового

### Валидация:

- **Размер файла**: максимум 5MB
- **Типы файлов**: PNG, JPG, JPEG, GIF, WebP
- **Длина bio**: максимум 500 символов

### Производительность:

- Превью аватара создается на клиенте перед загрузкой
- Оптимизированные запросы к API
- Кэширование данных профиля

## 🔍 Troubleshooting

### Аватар не загружается:

1. **Проверьте размер файла** - максимум 5MB
2. **Проверьте формат** - только PNG, JPG, JPEG, GIF, WebP
3. **Проверьте права доступа** к директории `/home/hyax/backend/media/avatars/`
4. **Проверьте логи**: `docker-compose logs api`

### Профиль не отображается:

1. Проверьте консоль браузера (F12) на ошибки
2. Убедитесь, что миграции применены
3. Проверьте, что пользователь авторизован
4. Очистите кэш браузера (Ctrl+Shift+R)

### Bio не сохраняется:

1. Проверьте длину текста (максимум 500 символов)
2. Проверьте интернет-соединение
3. Проверьте логи бэкенда: `docker-compose logs api`
