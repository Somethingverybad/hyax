# Доступ к приложению с других устройств в локальной сети

## Быстрая инструкция

### Шаг 1: Узнайте IP адрес вашего компьютера

**macOS/Linux:**
```bash
# Вариант 1
ifconfig | grep "inet " | grep -v 127.0.0.1

# Вариант 2
ipconfig getifaddr en0

# Вариант 3 (самый простой)
hostname -I
```

**Windows:**
```bash
ipconfig
# Найдите IPv4 Address в разделе вашего Wi-Fi адаптера
```

Вы увидите что-то вроде: `192.168.1.100` или `192.168.0.50`

### Шаг 2: Запустите Docker контейнеры

```bash
cd /Users/andrejcerenev/project/sux-chat
docker-compose up -d
```

### Шаг 3: Откройте приложение на другом устройстве

На устройстве, которое находится в той же Wi-Fi сети:

1. Откройте браузер
2. Перейдите по адресу: `http://YOUR_IP_ADDRESS`
   Например: `http://192.168.1.100`

## Настройка для локальной разработки PWA (без Docker)

Если вы запускаете PWA локально (`npm run dev`), а бэкенд в Docker:

1. Узнайте IP адрес (как выше)
2. В файле `sux-chat-pwa/.env` укажите:
   ```
   VITE_API_URL=http://YOUR_IP_ADDRESS/api
   ```
   Например: `VITE_API_URL=http://192.168.1.100/api`

3. Запустите PWA:
   ```bash
   cd sux-chat-pwa
   npm run dev -- --host
   ```

4. На другом устройстве откройте: `http://YOUR_IP_ADDRESS:5173`

## Решение проблем

### "Не могу подключиться"

1. **Убедитесь, что устройства в одной сети:**
   - Проверьте Wi-Fi имя (SSID)
   - Убедитесь, что оба устройства подключены к одному роутеру

2. **Проверьте firewall:**
   ```bash
   # macOS - отключите блокировку входящих подключений
   # Системные настройки → Защита и безопасность → Брандмауэр
   
   # Linux
   sudo ufw allow 80/tcp
   ```

3. **Проверьте, что порт не занят:**
   ```bash
   # macOS
   lsof -i :80
   
   # Linux
   netstat -tulpn | grep :80
   ```

4. **Проверьте, что контейнеры запущены:**
   ```bash
   docker-compose ps
   ```

5. **Проверьте логи:**
   ```bash
   docker-compose logs nginx
   docker-compose logs pwa
   docker-compose logs api
   ```

### "CORS ошибка"

Если видите CORS ошибки, убедитесь что в `backend/sux_chat/settings.py` добавлен ваш IP:

```python
CORS_ALLOWED_ORIGINS = [
    "http://192.168.1.100",  # Ваш IP
    "http://192.168.1.100:5173",  # Если PWA локально
    # ... другие адреса
]
```

### Изменение порта

Если порт 80 занят, измените в `docker-compose.yml`:

```yaml
nginx:
  ports:
    - "8080:80"  # Внешний порт:внутренний порт
```

Тогда доступ будет: `http://YOUR_IP_ADDRESS:8080`
