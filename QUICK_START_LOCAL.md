# 🚀 Быстрый старт - подключение с другого устройства

## Ваш IP-адрес: 192.168.0.5

## Шаги:

### 1. Перезапустите API контейнер (чтобы применить изменения CORS)
```bash
docker-compose restart api
```

### 2. На другом устройстве (телефон, планшет, другой компьютер):

1. Убедитесь, что устройство подключено к той же Wi-Fi сети
2. Откройте браузер
3. Введите адрес: **http://192.168.0.5**
4. Приложение должно загрузиться!

## Если не работает:

1. **Проверьте, что контейнеры запущены:**
   ```bash
   docker-compose ps
   ```

2. **Проверьте, что порт 80 открыт:**
   ```bash
   docker-compose port nginx 80
   ```

3. **Проверьте логи:**
   ```bash
   docker-compose logs api
   docker-compose logs nginx
   ```

4. **Проверьте firewall (на macOS):**
   - Системные настройки → Защита и безопасность → Файрвол
   - Убедитесь, что Docker разрешен

5. **Попробуйте ping с другого устройства:**
   ```bash
   ping 192.168.0.5
   ```

## Безопасность

⚠️ **Для продакшена** верните в `backend/sux_chat/settings.py`:
```python
CORS_ALLOW_ALL_ORIGINS = False
```
И укажите конкретные домены/IP в `CORS_ALLOWED_ORIGINS`.
